# 피싱아이 (PhishEye)

> 의심스러운 문자를 붙여넣으면 **어느 문장이 왜 위험한지** 짚어주는 청소년 전용 사기 문자 판별·학습 웹앱

제5회 2026 대한민국 고등학생 AI·SW 개발 공모전 출품작

---

## 무엇을 하는가

문자를 붙여넣으면 0~100점의 위험도와 함께, 점수가 어떤 문구 때문에 나왔는지를 전부 보여준다.

```
[국제발신] 고객님 주소불명으로 택배 배송이 보류되었습니다.
오늘 내 미확인 시 반송처리 됩니다. 주소 확인 ▶ http://cj-delivery-check.top/1a2b

→ 78점 · 매우 위험
  +36 의심스러운 링크 (.top 저가 도메인 · http · 하이픈 과다)
  +16 국제발신 위장
  +14 시간 압박 ("오늘 내")
  +12 기관 사칭 ("택배")
```

## 화면

| 탭 | 내용 |
|---|---|
| 문자 분석 | 위험도 판정 + 근거 하이라이트 + 지금 해야 할 일 |
| 사기 문자 훈련 | 진짜/가짜 문자 구분 퀴즈 8문항 + 해설 |
| 당했을 때 | 링크 클릭 / 송금 / 협박 상황별 대응 절차와 신고처 |

## 설계 원칙

1. **근거 없는 점수는 만들지 않는다** — 모든 점수를 신호 단위로 분해해 공개한다
2. **문자 원문은 기기 밖으로 나가지 않는다** — 기본 분석은 100% 브라우저 안에서 실행되며 서버가 없다
3. **겁주지 않고 할 일을 알려준다** — 특히 협박 유형에서는 상담 창구를 함께 안내한다

## 실행

로컬에서 확인하려면:

```bash
python -m http.server 8123
```

브라우저에서 `http://localhost:8123` 접속.

`index.html`을 파일로 직접 열어도 동작하지만, 앱 설치와 오프라인 기능은 `http://localhost` 또는 HTTPS에서만 켜진다.

## 앱으로 설치

브라우저 메뉴에서 **"홈 화면에 추가"** 또는 **"앱 설치"**를 누르면 된다. 설치 파일도 스토어도 필요 없다.

설치하면 이런 게 된다.

- **오프라인 동작** — 탐지 엔진이 전부 브라우저 안에서 돌기 때문에 데이터가 없어도 판별된다
- **공유 시트 연동** — 문자 앱에서 `길게 누르기 → 공유 → 피싱아이`를 고르면 바로 분석된다. 분석 후 주소창에 남은 문자 내용은 즉시 지운다
- **홈 화면 바로가기** — 아이콘을 길게 누르면 '사기 문자 훈련', '당했을 때'로 바로 들어간다

네이티브 앱(APK)을 만들지 않은 건 의도적이다. 이 앱은 "문자로 온 앱 설치 요청은 무조건 거부하라"고 경고한다. 그런 앱이 설치 파일을 받으라고 하면 스스로 모순이 된다.

## AI 정밀 분석 (선택)

규칙 엔진이 놓칠 수 있는 새로운 수법을 보완하는 기능이다. Claude API 키를 직접 입력할 때만 동작하며, **키 없이도 나머지 모든 기능이 정상 동작한다.**

키는 브라우저의 localStorage에만 저장되고 다른 곳으로 전송되지 않는다.

## 구조

```
index.html          화면 구조 (3개 탭)
manifest.json       앱 정보 — 아이콘, 공유 시트 연동, 바로가기
sw.js               서비스워커 — 오프라인 동작
assets/
  rules.js          탐지 규칙 엔진 — 17종 신호 + URL 분석 + 점수 합산
  samples.js        예시 문자 5종 + 훈련 퀴즈 8문항
  app.js            화면 제어, 결과 렌더링, 퀴즈, AI 호출, 앱 설치
  style.css         반응형 + 다크모드
  icon.svg          로고 (눈 + 낚싯바늘)
  icon-*.png        앱 아이콘 (192 / 512 / iOS 180)
```

개발기획서(`docs/`)는 공모전 심사가 끝날 때까지 저장소에 포함하지 않는다.

파일을 고칠 때는 `sw.js`의 `VERSION`도 올려야 한다. 안 올리면 사용자가 옛날 캐시를 계속 본다.

새로운 사기 수법이 등장하면 `assets/rules.js`의 `RULES` 배열에 항목을 추가하기만 하면 된다.

## 검증

| 구분 | 결과 |
|---|---|
| 사기 문자 5건 | 전부 '위험' 이상 (42점~100점) |
| 정상 문자 3건 | 전부 0점 |
| 일상 대화 3건 (`ㅋㅋ`, `ㅠㅠ` 포함) | 전부 0점 |

## 유의사항

판정 결과는 참고용이며 100% 정확하지 않다. 최종 판단은 공식 기관 확인을 거쳐야 한다.
예시 문자와 퀴즈 문항은 실제 사례를 참고해 재구성한 것으로, 실존하는 전화번호·도메인은 사용하지 않았다.
